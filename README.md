Statistik Indonesia — a national statistics site for Indonesia: population, economy, prices, labour and living standards, built from published official data (BPS — Statistics Indonesia; Bank Indonesia) as plain static files with no network requests. Eight linked sections, hand-drawn SVG charts, a working year selector, a searchable and sortable 38-province table, and downloadable CSV data.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. No build step, no dependencies.
